# ESP32 边缘环境感知从机固件 (EdgeNode_A_Sensor)

本工程运行于 ESP32 从机节点上，负责室内微环境多维参数（温湿度、大气压强、照度）的周期性采集，并通过 LEDC PWM 实现单色照明灯具的平滑调光，基于 ESP-NOW 与主控端保持无线双向通信。

---

## 引脚分配与电气连接

| 挂载模块 | 模块引脚 | ESP32 GPIO | 接口类型 / 说明 |
| :--- | :--- | :--- | :--- |
| **0.91 寸 OLED 屏** | SCL / SDA | **GPIO 1 / GPIO 2** | 软件 I2C (128x32 分辨率本地状态屏) |
| **DHT11 温湿度** | DATA | **GPIO 5** | 单总线通信 (带上拉电阻) |
| **单色照明执行器** | PWM 控制端 | **GPIO 6** | LEDC 高频 PWM 输出 (5kHz, 8-bit 分辨率) |
| **MS5611 / GY-63 气压计** | SDA / SCL | **GPIO 11 / GPIO 12** | 硬件 I2C (Wire1，CSB 接地锁定 0x77 地址) |
| **VEML7700 高精度光照计** | SDA / SCL | **GPIO 11 / GPIO 12** | 与气压计并联挂载于硬件 I2C 总线 |

---

## 核心设计与工作机制

### 1. I2C 传感器总线复用
* `GY-63`（MS5611 气压计）与 `VEML7700`（光照计）共用 `GPIO 11` 与 `GPIO 12` 硬件 I2C 总线，分别通过各自唯一的 I2C 从机地址进行寻址通信。

### 2. LEDC PWM 无级调光
* 基于 ESP32 硬件 LEDC 定时器，根据主控端下发的目标占空比（0%~100%），以毫秒级步进平滑过渡，消除灯具开关突变与人眼可察觉的闪烁感。

### 3. ESP-NOW 无线通信与低功耗策略
* 采用免路由连接的 ESP-NOW 私有协议与 ESP32-S3 主控端交互。
* 接收到主控查询或控制指令后，射频保持唤醒 3 秒以保障连续指令回执；空闲时进入周期性间歇休眠以降低整机运行功耗。

# 编译并烧录至 ESP32
