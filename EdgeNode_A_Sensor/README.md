本文档整理了从机节点 **`EdgeNode_A_Sensor`** 的最新硬件接线与 GPIO 规划，涵盖全部环境传感器外设与智能照明执行器。

## 💡 核心设计与使用说明

1. **I2C 共享总线**：
   - `GY-63`（MS5611 气压/温度）与 `VEML7700`（高精度环境光照）共用 `GPIO 11 (SDA)` 与 `GPIO 12 (SCL)`，无需额外占用引脚。
2. **多环境数据感知与照明执行**：
   - 具备温度、湿度、气压及光照强度的毫秒级响应采集能力；
   - 支持主控通过 ESP-NOW 下达 0~100% 细分 PWM 平滑无级调光。
3. **ESP-NOW 低功耗与高响应策略**：
   - 收到主控指令后射频常开 3 秒，确保多传感器连续查询与回执一次命中；
   - 平时执行 300ms 醒 / 250ms 睡的轻度省电轮转循环。
