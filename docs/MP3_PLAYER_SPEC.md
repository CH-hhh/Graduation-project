# 嵌入式双核异构 MP3 音乐播放器系统架构与设计规范

本文档整理了本项目（STM32H743 后端媒体服务器 + ESP32-S3 前端交互与声卡中控）关于 **SD 卡 MP3 音乐播放器** 的全套系统需求、总线规划、协议规范与界面设计要求。

---

## 🏗️ 一、 总体系统架构与角色分工

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                              【STM32H743 后端媒体服务器】                              │
│                                                                                        │
│  [MicroSD 卡] ──SDMMC 4-bit DMA──> [FatFs 文件系统] ──> [Helix MP3 定点数软解码引擎]   │
│                                                                   │                    │
│  [播放状态机 (播放/暂停/下一曲/进度/音量/ID3标签)] <───────────────┴──> [PCM 数据帧]   │
└───────────────────────┬───────────────────────────────────────────────────┬────────────┘
                        │                                                   │
           【双向控制总线 (UART RPC)】                             【高速数据总线 (SPI DMA)】
           • 全双工 115200 波特率                                 • 单向 20MHz DMA 极速推送
           • 专跑指令控制、歌单同步、播放状态与歌词                • 专跑实时音频 PCM 流 & 摄像头帧
                        │                                                   │
┌───────────────────────▼───────────────────────────────────────────────────▼────────────┐
│                             【ESP32-S3 前端交互与播放终端】                            │
│                                                                                        │
│  [TFT ST7789 屏幕 (商用级 MP3 播放 UI)] <── [PSRAM 环形水库 256KB] ──> [I2S DMA 引擎]  │
│  • 歌名/歌手/歌词/进度条/歌单抽屉/动效频谱                                   │          │
│  • 摇杆与按键交互捕获                                                         ▼          │
│                                                                      [NS4168 数字功放]  │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1. 前端（ESP32-S3）职责
* **纯前端交互终端**：负责 TFT 屏幕商用级播放器 UI 绘制与动效；
* **用户输入采集**：采集摇杆（上下选歌、左右快进/调音、按下播放/暂停）与物理按键；
* **双向控制指令转发**：通过 UART 发送控制指令给 STM32，接收 STM32 反馈的歌单与状态；
* **声卡播放引擎**：通过 8KB SRAM 乒乓缓冲接收 SPI 音频流，存入 256KB PSRAM 环形大水库，经由 I2S 驱动 NS4168 功放放音。

### 2. 后端（STM32H743）职责
* **存储与文件系统**：通过 SDMMC 4-bit 硬件 DMA 挂载 FatFs，扫描 SD 卡目录与构建歌单索引；
* **ID3 标签解析**：解析 MP3 的 `ID3v2` / `ID3v1` 标签，提取歌曲名、歌手、专辑信息；
* **MP3 软解码引擎**：运行高效 `Helix MP3` 算法库，将压缩帧流式解压为 16-bit PCM；
* **播放状态机管理**：处理当前播放状态（PLAY/PAUSE/STOP）、当前播放时间、总时长计算；
* **数据流发送**：通过 SPI2 Master TX DMA 以 20MHz 速率将 PCM 块推送至 ESP32。

## 🔌 二、 物理总线与引脚分配

| 总线类型 | 信号名称 | ESP32-S3 引脚 | STM32H743 引脚 | 功能描述 |
| :--- | :--- | :--- | :--- | :--- |
| **控制总线 (UART)** | **TX ➡️ RX** | **GPIO 0** (TX) | **STM32 RX** | ESP32 发送播放/暂停/切歌/音量/选歌控制指令 |
| **控制总线 (UART)** | **RX ⬅️ TX** | **GPIO 48** (RX) | **STM32 TX** | STM32 上报歌单列表、播放进度、歌曲元数据 |
| **数据总线 (SPI)** | **MOSI** | **GPIO 45** | **PB15 (MOSI)** | STM32 向 ESP32 高速推送 PCM 音频流 |
| **数据总线 (SPI)** | **MISO** | **GPIO 39** | **PB14 (MISO)** | 辅助状态反馈与随路通信 |
| **数据总线 (SPI)** | **SCK** | **GPIO 38** | **PB13 (SCK)** | 20MHz 高速同步时钟 |
| **数据总线 (SPI)** | **CS / NSS** | **GPIO 47** | **PB12 (NSS)** | 片选信号 |
| **硬件流控** | **HANDSHAKE** | **GPIO 21** | **PB1 (Handshake)** | ESP32 PSRAM 水库高低水位流控信号 |
| **共地** | **GND** | **GND** | **GND** | 两板系统统一参考地 |

## 💬 三、 UART 双向控制协议设计 (115200 8-N-1)

所有指令以换行符 `\n` 结尾：

### 1. 前端发往后端（ESP32 ➡️ STM32）
* `CMD:GET_LIST\n`：请求获取 SD 卡全部歌曲列表；
* `CMD:PLAY,<track_id>\n`：请求播放指定序号的歌曲（如 `CMD:PLAY,3`）；
* `CMD:PAUSE\n`：暂停播放；
* `CMD:RESUME\n`：恢复播放；
* `CMD:STOP\n`：停止播放；
* `CMD:NEXT\n`：播放下一首；
* `CMD:PREV\n`：播放上一首；
* `CMD:SEEK,<seconds>\n`：快进/快退到指定秒数；
* `CMD:VOL,<0-100>\n`：设置播放音量；
* `CMD:MODE,<0/1/2>\n`：播放模式切换（0=顺序播放, 1=单曲循环, 2=随机播放）。

### 2. 后端上报前端（STM32 ➡️ ESP32）
* `LIST_START\n`：歌单开始；
* `ITEM:<id>,<file_name>,<duration_sec>,<artist>\n`：单首歌曲信息；
* `LIST_END\n`：歌单结束；
* `STATUS:<state>,<cur_sec>,<total_sec>,<volume>,<mode>,<track_id>\n`：周期性（每 500ms）上报播放状态；
* `LYRIC:<cur_sec>,<lyric_text>\n`：当前时刻歌词文本同步。

## 🎨 四、 前端（ESP32 端）商用级 MP3 播放器界面与交互规划

页面分为 **【主播放界面 (Main Player)】** 和 **【歌单选择抽屉 (Playlist Modal)】**：

### 1. 主播放界面功能区域（商用 MP3 标配）
1. **顶栏状态**：当前曲目序号（如 `[03/28]`）、播放模式图标（`[顺序/循环/随机]`）、当前音量（`Vol: 80%`）；
2. **曲目与元数据区**：
   * 🎵 **歌曲名称**（大字号加粗高亮，支持长歌名平滑跑马灯滚动）；
   * 👤 **歌手 / 专辑信息**（次级字体，精致灰/主色调）；
3. **中央歌词 / 动效区**：
   * 🌟 **实时同步动态歌词**（当前句高亮金色加粗，上下淡出平滑过渡）；
   * 📊 **动态音频跳动频谱柱状动效**（底部 16~24 根律动条，随音乐振幅跳跃）；
4. **高精度时间与进度条区**：
   * 进度条两端精确标注：`已播放时长 (如 01:23)` ─────●────── `总时长 (如 04:15)`；
   * 进度条采用高亮主色填充，带圆形发光滑块指示；
5. **底部控制按键区（等宽对称精致布局）**：
   * `[ 模式 ]` ── `[ 上一曲 ]` ── `[ 播放/暂停 ]` ── `[ 下一曲 ]` ── `[ 歌单 ]`

### 2. 歌单选择抽屉（Playlist Modal / Drawer）
* 按下 `[歌单]` 按键或摇杆特定动作呼出悬浮歌单卡片；
* 列表滚动显示 SD 卡中所有歌曲（序号、歌名、时长）；
* 当前正在播放的歌曲带金色小喇叭高亮指示；
* 摇杆上下滚动选歌，按下直接秒切播放，按返回键关闭歌单。

### 3. 摇杆与按键交互映射
* **摇杆上下**：音量增减（主界面） / 歌单上下滚动（歌单界面）；
* **摇杆左右**：快退 5 秒 / 快进 5 秒（长推），或短推切换上一首/下一首；
* **摇杆中键按下**：播放 / 暂停切换（主界面） / 选中确认播放（歌单界面）；
* **返回键 (GPIO 18)**：退出歌单 / 返回主页。
