# 基于大模型的桌面智能语音终端

本项目是一套多硬件协同的桌面语音交互终端系统。系统由 ESP32-S3 主控、STM32H743 媒体协处理器与 ESP32 环境传感从节点组成，端侧支持离线语音唤醒，云端通过接入通义千问大模型与 Function Calling 工具调用实现多轮会话、视觉理解和外设控制。

---

                       └────────────▲────────────┘

│                     ESP32-S3 主控端                                     │

│  • 2.8 寸 ST7789 彩屏 UI 渲染 (自研轻量 C++ UI)                        │
│  • 原生 USB CDC 桌面投屏                                                │
└───────────────────┬─────────────────────────────────┬───────────────────┘
                    │ 20MHz SPI DMA / UART            │ ESP-NOW (2.4GHz)
                    ▼                                 ▼
┌───────────────────────────────────────┐ ┌───────────────────────────────┐
│      STM32H743 媒体协处理器           │ │     ESP32 环境感知从节点      │
│  • OV2640 摄像头画面捕获与 SPI 推流    │ │  • DHT11 (温湿度采集)        │

### 总线与接口规划

| 总线协议 | 物理接口 | 传输方向 | 传输内容与速率 |
| :--- | :--- | :--- | :--- |
| **SPI DMA** | 硬件 SPI (SCK, MISO, CS) | STM32 ➔ ESP32-S3 | 摄像头视频帧及解码后的 PCM 音频流，速率 20MHz |
| **UART** | 串口 (TX/RX) | 双向全双工 | 控制指令交互、播放状态机同步、歌单与 LRC 歌词，115200 bps |
| **ESP-NOW** | 2.4GHz 私有无线协议 | 双向无连接 | 传感器周期数据上报与 PWM 调光控制包，微秒级延迟 |

## 核心实现说明

### 1. 语音唤醒与大模型交互 (ESP32-S3)
* **端侧离线唤醒**：提取 16 通道 Mel 滤波器组特征与 MFCC 参数，通过 8 阶段 DTW（动态时间规整）进行模板匹配，实现本地免联网离线唤醒词检测。
* **流式交互与工具调度**：采用流式 SSE 请求通义千问模型，支持多轮对话上下文。注入工具协议（Tools Schema），大模型根据意图自动触发对应 Skill（如天气查询、环境数据播报、音乐控制与灯光调节）。
* **自研轻量 UI**：基于纯 C++ 实现卡片式界面排版，摒弃沉重的通用 GUI 框架以节省约 150KB SRAM，提供 10 个系统状态及功能面板。

### 2. 媒体处理与推流 (STM32H743)
* **图像捕获**：通过 DCMI 接口连接 OV2640 模组，配合 DMA 乒乓缓冲进行图像采集，并通过 20MHz SPI 将画面推至主控屏显或用于多模态拍照问答。
* **音频解码与同步**：挂载 SD 卡 FatFS 文件系统，通过 Helix MP3 算法库完成定点数解码。同步检索同名 LRC 歌词文件，基于时间轴切片逐行下发。
* **歌单排序**：集成 GBK 汉字拼音索引表，在微控制器本地自动按拼音字母顺序（A-Z）完成歌单排序。

### 3. 微环境感知与调光 (ESP32)
* **环境检测**：板载 DHT11、MS5611 气压计及 VEML7700 高精度光敏模块，定时周期轮询采集室内温湿度、气压与照度数据。
* **执行器控制**：利用 ESP32 硬件定时器与 LEDC 输出高频 PWM 信号，实现单色照明灯具的 0%~100% 平滑调光。

## 编译与配置指南

### 1. 密钥与网络配置
在 `Master_Gateway_S3/include/` 目录下复制配置模板并填入本地 WiFi 与 API 密钥：
```bash
cp Master_Gateway_S3/include/private_config.example.h Master_Gateway_S3/include/private_config.h
```
> 注：`private_config.h` 已被 `.gitignore` 忽略，不会上传到远端仓库。

### 2. 构建与烧录
各子模块均使用 PlatformIO 进行依赖管理与编译：

```bash
# 编译并烧录主控端 (ESP32-S3)
cd Master_Gateway_S3
pio run -e esp32s3box -t upload

# 编译并烧录传感器从机 (ESP32)
cd ../EdgeNode_A_Sensor
pio run -e esp32s3 -t upload

# 编译并烧录媒体协处理器 (STM32H743)
cd ../stm32cam
pio run -e genericSTM32H743VI -t upload
```
